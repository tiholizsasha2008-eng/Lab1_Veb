# Wishlist App — Список бажань

Практична робота №1 з курсу клієнтської веброзробки (Варіант 7).

## Опис проєкту
Клієнтський вебзастосунок для ведення списку бажаних покупок з можливістю вказувати ціну та пріоритет речей.

## Заплановані розділи
1. Шапка з назвою застосунку
2. Форма додавання нового бажання
3. Список бажаних речей (картки з ціною й пріоритетом)
4. Блок підсумкової суми
5. Підвал

## Структура проєкту
- `index.html` — базовий HTML5-каркас
- `css/style.css` — стилі застосунку
- `js/app.js` — клієнтська логіка
