# Wishlist App — Список бажань

Вебзастосунок для ведення списку бажаних покупок з можливістю вказувати ціну, пріоритет речей, зберігати дані локально та завантажувати список бажань із локального сервера (Варіант 7).

## Реалізовані розділи
1. Шапка з назвою застосунку та навігацією (SPA-маршрути)
2. Форма додавання нового бажання
3. Список бажаних речей (картки з ціною, пріоритетом і прогресом накопичення)
4. Блок підсумкової суми
5. Розділ «Бажання із сервера» з отриманням даних через Fetch API
6. Підвал

## Структура проєкту
- `index.html` — головна HTML5-сторінка застосунку
- `css/style.css` — стилі застосунку
- `script.js` — клієнтська логіка, маршрутизація та запити до API
- `server/server.js` — локальний Express-сервер (роздача статики та API)
- `server/data/wishes.json` — локальний JSON-файл із переліком бажань
- `server/package.json` — конфігурація та залежності сервера

## Запуск сервера (практична №14)

```bash
cd server
npm install
npm start
```
